# 网页控制大师

[![Edge Add-on](https://img.shields.io/badge/Edge-商店-0078D7?style=flat-square&logo=microsoft-edge)](https://microsoftedge.microsoft.com/addons/detail/mmgfooecliddbadakcegfmjigjagllnh)
[![GitHub release](https://img.shields.io/github/v/release/Fxalll/WebControlMaster?style=flat-square&logo=github)](https://github.com/Fxalll/WebControlMaster/releases)
[![GreasyFork](https://img.shields.io/badge/GreasyFork-脚本-660000?style=flat-square&logo=tampermonkey)](https://greasyfork.org/)

> **一款功能强大的网页增强工具 —— 集图片管理、隐私保护、自动化操作于一体。**

网页控制大师是一个浏览器扩展 / 用户脚本，提供从基础的图片隐藏与放大，到高级的自动化操作、隐私保护等丰富功能，让网页控制更加得心应手。

---

## 这玩意儿是干嘛的？

一句话：**这是一个让你能「操控网页」的浏览器扩展。**

有些网页看着烦、用着累、操作重复。这个工具就是让你能按自己的方式来控制网页，而不是被网页控制。

---

## 解决什么问题？

| 场景 | 痛点 | 怎么解决 |
|------|------|----------|
| 看文章 | 图片太多，晃眼 | 一键隐藏所有图片，清静阅读 |
| 翻素材 | 图片散在各处，不好找 | 阅兵模式把所有图片铺开，一目了然 |
| 看图 | 图太小，看不清细节 | 悬停/中键/点击都能放大，还能看图片信息 |
| 离开电脑 | 怕别人看到屏幕内容 | 隐私锁自动上锁，PIN码解锁 |
| 页面敏感信息 | 有些区域不想让人看见 | 拖拽画个框遮住，颜色自动匹配背景 |
| 浏览记录 | 不想让人知道在看什么站 | 标签标题和图标伪装成Office/GitHub |
| 重复操作 | 每天点同样的按钮、填同样的内容 | 录一遍操作，之后自动执行 |
| 等消息 | 刷新页面等某个内容出现 | 监控页面变化，出现后弹窗提醒你 |
| 复制数据 | 页面表格/列表不好复制 | 点选一个元素，自动采集同类数据，导出表格 |
| 页面文字 | 某些词看着不顺眼 | 自动替换成你想看的词 |

## 跟同类工具有啥不一样

| | 网页控制大师 | 其他工具 |
|--|-------------|----------|
| 功能范围 | 功能强大 | 较为单一 |
| 用户体验 | 着重交互体验，动画必须符合操作直觉 | 通常只追求可用能用 |
| 上手难度 | 装上就能用，不需要配置 | 很多需要看教程 |
| 配置方式 | 作用域分级（当前页/网站/全局） | 要么全局要么没有 |
| 数据 | 全本地，不上传 | 有些需要联网 |

## ✨ 功能概览

### 🖼️ 图片控制
- **一键隐藏/显示**：点击指示灯，自动隐藏当前页面所有图片，大幅提升专注度
- **多种放大方式**：悬停放大、点击放大、中键放大
- **放大图时自动高清替换**：自动识别并加载高清原图
- **智能管理**：自动处理新加载的图片，支持滚动加载场景
- **钉图模式**：固定多个放大图片，方便对比查看
- **智能模糊调节**：根据隐藏图片数量自动调节模糊程度，优化性能
- **自动禁用动画**：隐藏图片超过阈值（默认80张）时自动禁用 CSS 过渡动画，保证页面流畅

### 👁️ 图片阅兵
- **网格化展示**：将所有图片以网格形式整齐排列
- **高清替换**：自动识别并加载高清原图
- **尺寸过滤**：可按图片尺寸筛选
- **批量下载**：一键打包下载所有图片
- **交互操作**：拖动、缩放、3D旋转图片查看图片信息

### 🔐 隐私保护
- **网页隐私锁**：
  - 手动/失焦/超时三种锁定模式
  - PIN 码解锁
  - 忘记密码跳过解锁（可记录日志）
  - 自定义锁屏外观（背景色、文字色、时间格式等）
  - 快捷键上锁
- **局部遮罩**：在页面上绘制遮罩区域，保护敏感内容
  - 支持智能取色（自动匹配背景）
  - 可调节透明度、圆角、模糊度
  - 支持固定在屏幕或跟随页面滚动
- **标签伪装**：伪装浏览器标签页标题和图标
  - 预设标题/图标模板
  - 支持自定义标题和图标

### 🤖 自动化工具
- **自动点击器**：
  - 支持点击元素、点击位置、输入文字、快捷键、延时、智能等待等操作
  - 可视化步骤编辑，支持拖拽排序
  - 循环执行（可设为无限循环）
  - 一键录制操作序列
  - 支持作用域：仅当前页 / 当前网站
  - 安全延迟设置
- **页面监控器**：
  - 监控页面元素变化（文本变化、包含/不包含关键词、数值比较、出现/消失）
  - 触发后执行：弹窗提醒、桌面通知、刷新页面、自动点击
  - 支持 CSS 选择器和 XPath
- **数据采集**：
  - 可视化采集页面结构化数据
  - 智能识别相似元素
  - 支持表格展示、编辑、删除
  - 导出为 CSV / HTML / JSON
  - 支持持续抓取（翻页自动采集）

### ✏️ 页面工具
- **文字替换**：自动替换页面中的指定文字
  - 支持区分大小写
  - 按优先级：仅当前页 > 当前网站 > 全局通用
- **页面可编辑**：一键开启页面编辑模式（类似 Word）
- **快捷文本**：设置快捷键后在任意输入框快速填入预设文本

### 其他
- **随心一问**：基于提问内容与时间、节气等随机因素生成趣味答案

## 🎯 快速上手

| 操作 | 说明 |
|------|------|
| **点击指示灯** | 开启/关闭图片隐藏功能（🟢 开启 / 🔴 关闭 / 🟡 动画已禁用） |

| **中键点击克隆图** | 关闭该图片的放大视图 |

## 🛠️ 开发相关

### 技术栈
- 原生 JavaScript（无第三方依赖）
- 浏览器扩展 API（`chrome.storage` / `localStorage`）
- MutationObserver / IntersectionObserver
